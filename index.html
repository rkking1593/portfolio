· About ·

A little about how I work.

I'm a full-stack developer from Uttar Pradesh, India, currently pursuing my BCA at Amity University Online, and co-founder of Codenosis, a web development and tech education blog. I write, correct, and deploy code myself — I'd rather understand why something works than copy-paste a fix. LuxeLane, a fully functional e-commerce storefront with cart, wishlist, and search, was built from scratch in 4 days.

Alongside frontend, I build real backend systems — Node, Express, MySQL, JWT auth — and I've shipped a deployed CMS that runs my own blog's publishing workflow. I care about code that's honest: no invented stats, no fabricated content, no over-engineering a problem that needed a simple solution.
